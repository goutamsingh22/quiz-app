
# Quiz Application

A responsive quiz application built with HTML, CSS, and JavaScript featuring multiple-choice questions, timer, scoring, and detailed results.

## Features

- **Multiple Choice Questions** - 5 predefined questions with 4 options each
- **Timer** - 30 seconds per question with visual warning when time is running low
- **Scoring System** - 1 point for each correct answer
- **Results Page** - Shows final score, percentage, and personalized message
- **Answer Review** - Detailed review of all questions with correct and user answers
- **Responsive Design** - Works on desktop and mobile devices
- **Smooth Animations** - Fade transitions between screens

## How to Use

1. Open `index.html` in your web browser
2. Click "Start Quiz" to begin
3. Select an answer for each question or wait for timer to expire
4. Click "Next Question" to proceed
5. View your results and review answers at the end
6. Click "Restart Quiz" to try again

## Files

- `index.html` - HTML structure with all screens
- `style.css` - Styling and responsive design
- `app.js` - Quiz logic, timer, and scoring functionality

## Technologies Used

- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- Vanilla JavaScript (ES6+)
